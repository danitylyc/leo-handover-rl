# LEO 卫星切换强化学习（LEO Handover RL）

**为密集低轨（LEO）星座学习卫星切换决策。**

一个从零开始、自包含的项目：把"由哪颗卫星服务移动地面终端"建模为强化学习问题。包含轻量物理 LEO 仿真器（轨道几何、Ku 波段链路预算、逐星负载动态）、手写的 double-DQN 智能体、四个经典启发式基线、以及可复现的训练/评估/绘图管线。**无任何 RL 库、无卫星工具包依赖**——全部是 numpy + torch。

---

## 为什么研究这个问题

LEO 巨型星座（Starlink、OneWeb 等）会让终端同时处于**多颗卫星视野内**，而服务卫星几分钟内就升起又落下。每次*切换*决策都要权衡：

- **链路质量** —— SINR 取决于仰角（斜距）与逐星增益；
- **切换代价** —— 信令、重新捕获、波束切换的开销；
- **负载均衡** —— 过热卫星会让它所服务的所有用户变差。

经典启发式一次只优化其中一项（永远选最高的卫星、永远选信号最强的、永远选可见最久的）。没有哪一条能看全整个视野。学习策略原则上可以同时权衡三者——这正是本项目端到端探索的问题。

**值得知道的仿真级发现：** 550 km 轨道壳层只看到约 17° 地心角（约 1,900 km 地面足迹），所以稀疏星座存在**结构性覆盖空洞**，任何策略都无法填补。只有当星座足够密集、能保证可见候选时，切换决策才有意义——本仓库所用配置（24 面 × 8 星）在整个回合内始终保持可见候选（实测中断率约 2.5–3%，大部分发生在切换边界）。

## 仓库内容

| 模块 | 作用 |
|---|---|
| `sim/leo_sim.py` | 纯 numpy 的 LEO 切换 MDP：Walker 星座、ECEF 几何、仰角/可见性、Ku 链路预算、负载动态 |
| `agents/dqn.py` | 手写 double DQN（128×2 MLP、回放、软目标更新） |
| `agents/heuristics.py` | 4 个经典基线：`nearest`、`max-sinr`、`longest-los`、`keep-or-nearest` |
| `train_dqn.py` | 多种子训练、检查点、固定轨迹评估、CSV 日志 |
| `evaluate.py` | 50 条留出轨迹的正面对决：DQN 集成 vs 全部基线 |
| `plot_results.py` | 学习曲线 + 对比图 |

### 仿真器模型（概要）

- **轨道：** 圆形 550 km、倾角 53°、24 面 Walker 相位排列；轨道面在惯性系固定，地球在下方自转（RAAN 在 ECEF 中向西漂移）。
- **链路预算：** Ku 12 GHz、点波束 EIRP 50 dBW、接收噪声底 −125 dBW、自由空间路径损耗；逐星增益偏差（±6 dB）模拟载荷差异。
- **终端：** 低纬度移动用户（10–40 m/s），仰角掩蔽 10°。
- **MDP：** 状态 = [终端大地位置 (2)] + [服务星：仰角、SINR、负载 (3)] + 前 K 候选描述：仰角、SINR、剩余可见时长、负载 (4K)——候选按仰角降序排列，可见数不足时补齐；动作 = {保持，候选槽 1..K}；奖励 = 链路质量 − 0.4·负载 − 1.0·切换 − 3.0·中断。

## 结果（50 条留出轨迹均值，确定性种子）

> 下表数字由 `evaluate.py` 从仓库内检查点产出。见图 `results/comparison.png` 与 `results/training_curves.png`。

| 策略 | 平均质量 | SINR (dB) | 切换/回合 | 中断率 | 公平性 | 奖励 |
|---|---|---|---|---|---|---|
| **dqn（3 种子集成）** | **0.579** | 1.60 | **4.8** | 0.027 | 0.017 | **84.3** |
| max-sinr | 0.603 | **2.30** | 10.1 | 0.026 | 0.014 | 79.0 |
| longest-los | 0.550 | 1.24 | 10.5 | 0.025 | 0.015 | 66.9 |
| nearest | 0.550 | 1.24 | 10.5 | 0.025 | 0.015 | 66.9 |
| keep-or-nearest | 0.504 | 0.33 | 9.3 | 0.031 | 0.013 | 38.7 |

**学习策略实际做了什么：** max-sinr 每步追逐最强信号（质量最好、切换最多）。DQN 策略在链路仍好时保持、只在服务星质量即将下滑时切换——**切换次数减半（4.8 vs 10.1），代价仅是 4% 的质量损失，最终拿到最高的总奖励（比最优启发式 +6.7%）**。这正是全部要点：γ=0.99 的价值函数隐含地向前看，贪心的单目标启发式做不到。

## 复现

```bash
pip install numpy torch matplotlib      # CPU torch 即可

# 训练 3 个种子（检查点与评估日志在 runs/ 下）
python train_dqn.py --seed 1 --episodes 1200 --out runs
python train_dqn.py --seed 2 --episodes 1200 --out runs
python train_dqn.py --seed 3 --episodes 1200 --out runs

# 50 条留出轨迹的正面对决评估
python evaluate.py --model runs/seed1/dqn_final.pt --seeds 1,2,3

# 绘图
python plot_results.py
```

## 说明 / 诚实的局限

- **覆盖保证：** 密集 24×8 单壳层配置是简化——真实星座靠堆叠多个壳层实现连续性。`_sat_ecef` 中的几何正是需要换成 TLE/传播器以追求真实感的部分。
- **无链路层细节：** 无调制、无衰落、无波束指向；SINR 以路径损耗为主导。
- **单终端回合：** 负载均衡通过状态/奖励中的逐星负载进入；真正的多终端竞争是自然的下一步（MARL）。
- 学习曲线如实绘制实际发生的情况，包括早期的不稳定。
